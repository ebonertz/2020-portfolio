01 / Production AIISC · Current work

AI for insurance underwriting and quote analysis

Turning complex insurance data and unstructured quote documents into useful information for underwriters.

  • LLM APIs
  • TypeScript
  • Node.js
  • AWS

The challenge

Underwriters need to compare dense, inconsistent quote documents and connect information across systems. The workflow calls for reliable APIs, structured outputs, and clear human judgment.

My role

I designed APIs and databases supporting an AI underwriting platform, built an LLM-assisted quote comparison tool, and integrated an AI-based Excel rating engine for real-time quotes. I also contribute to cloud deployment, planning, and mentoring.

What it demonstrates

Production AI integration, document analysis, cloud engineering, and delivery in a complex insurance environment.

03 / Applied AINido / EZ Vibes · In progress

An AI-assisted workflow for a real community product

Using event data, tools, and human review to make a local music newsletter more useful and repeatable.

  • GCP
  • Agents
  • MCP
  • Human review
Event data→Selection & reasoning→Draft→Human review

The problem

Producing a useful events newsletter takes recurring discovery, selection, context, and editorial judgment. The work is repetitive, but the final choices should still reflect the community and a human editor.

My approach

I’m building the Nido event platform and designing an agent workflow to gather candidate events, propose selections, explain the reasoning behind them, and prepare a draft for review. The design keeps human approval before publication.

Current state

The event product is active; the newsletter agent is an ongoing build. I’m using it to deepen my practice in tool-connected AI systems, traceability, and production-minded automation.

What it demonstrates

Product ownership, applied cloud architecture, careful agent design, and a bias toward workflows that solve a real operating problem.
